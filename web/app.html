使用步骤 / 排障
  1. USB 线插到 P4 的 高速口，等设备枚举完成（资源管理器里出现 MeidaP4 的 MTP 卷）。
  2. 点「连接设备」→ Chrome 弹窗里选中 MeidaP4 Composite（VID 303A / PID 4103）→ 允许。
  3. 页面会自动 claim IF1（视频 EP 0x83 IN） 与 IF2（控制 EP 0x84 IN / 0x04 OUT）， 然后等设备发 HELLO；收到后自动回 HELLO_ACK 并开始出画面。
  4. claim IF1 失败 ⇒ 固件这一版没把 IF1 绑到 WinUSB（WCID）：换 Lead 刚烧的固件、 拔插一次、并关闭其它占用该设备的 Chrome 标签页。
  5. RFC 提醒：只有 Chrome / Edge（Chromium）支持 WebUSB；Firefox / Safari 没有 navigator.usb。
